# 학교 업무 자동화 도구 모음

반복적인 학교 행정·문서·안내 업무를 안전하게 줄이는 작은 도구와 사용법을 모으는 공개 프로젝트입니다.

이 프로젝트는 컴퓨터에 익숙하지 않은 교직원도 쉽게 이해하고 사용할 수 있는 도구를 만드는 것을 목표로 합니다.

## 프로젝트 원칙

1. **개인정보를 보호합니다.** 학생·보호자·교직원의 개인정보와 비공개 학교 자료를 저장소에 올리지 않습니다.
2. **사람이 최종 확인합니다.** 자동으로 만든 문서나 결과는 담당자가 검토한 뒤 사용합니다.
3. **작은 기능부터 만듭니다.** 한 번에 복잡한 시스템을 만들기보다 반복 업무 하나씩 개선합니다.
4. **사용법을 쉽게 설명합니다.** 전문 용어를 줄이고 초보자용 안내를 함께 제공합니다.
5. **비밀 정보를 저장하지 않습니다.** 비밀번호, API 키, 인증 토큰 등은 코드나 예시 파일에 포함하지 않습니다.

## 초기 도구 아이디어

- 안내문과 공지문 초안 도우미
- 자주 사용하는 문구와 서식 템플릿
- 정해진 규칙에 따른 파일명 정리
- 공개 데이터만 활용하는 업무 체크리스트

구체적인 첫 도구는 필요성, 안전성, 사용 난이도를 검토한 뒤 선정합니다.

## 현재 상태

현재는 **기획 및 초기 문서화 단계**입니다. 실행 가능한 프로그램은 아직 포함되어 있지 않습니다.

## 로드맵

- [ ] 첫 번째 도구 선정
- [ ] 최소 기능 구현
- [ ] 초보자용 설치·사용 방법 작성
- [ ] 예시 데이터로 기능 테스트
- [ ] 사용자 의견을 반영해 개선

## 안전 및 개인정보 보호

이 저장소는 공개되어 있습니다. 다음 정보는 예시 데이터로도 커밋하지 않습니다.

- 학생, 보호자, 교직원의 이름·연락처·학번 등 개인정보
- 성적, 상담, 건강, 생활기록 등 민감한 정보
- 학교 내부 문서와 비공개 업무 자료
- 계정 비밀번호, API 키, 인증 토큰

테스트가 필요할 때는 실제 사람이나 학교를 식별할 수 없는 가상의 데이터만 사용합니다.

## 참여 방법

기능을 추가하기 전에는 다음 사항을 먼저 확인합니다.

- 반복 업무를 실제로 줄일 수 있는가?
- 개인정보 없이 개발하고 테스트할 수 있는가?
- 컴퓨터 초보자도 사용할 수 있는가?
- 결과를 사람이 검토할 수 있는가?

프로젝트가 초기 단계이므로 구체적인 개발 및 기여 방법은 첫 도구를 선정한 뒤 추가할 예정입니다.
